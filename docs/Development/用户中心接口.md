# UserCenter

提供一系列用户相关的接口，以提供业务支持。

## 接口概要

所有接口(除登录外)都在header中传递token,如: `header: Authorization: {token}`

token是用户的`Guid::email::timestamp`，然后进行base64后的结果。timestamp是当前时间的时间戳，单位秒。

解析token,获取到用户的Guid/email/timestamp。timestamp判断日期是否相关在5s内；

guid/email共同用来查询用户是否存在，先从缓存中取，如果缓存中没有，则从数据库中查询，并将结果缓存起来，缓存时间为60分钟。

token验证不通过返回401。

### 接口列表

- 密码登录
- Token验证
- 添加代理使用流量记录

## 接口设计

### 密码登录

- **接口地址**：POST /api/userCenter/login
- **请求参数**：
  - Email: 用户邮箱
  - Password: 用户密码
- **返回结果**：登录成功返回Guid.

### 代理用量记录

- **接口地址**：POST /api/userCenter/proxyUsage
- **请求参数**：
  - Usage: 使用流量，单位字节

- **返回结果**：更新后的流量
- **实现逻辑**：根据服务器日期，查询当天的代理使用记录，如果存在则更新流量，否则创建新的记录。

### 代理用量查询

- **接口地址**：GET /api/userCenter/proxyUsage
- **请求参数**：
  - PageIndex
  - PageSize

- **返回结果**：更新后的流量
- **实现逻辑**：根据服务器日期，查询当天的代理使用记录，如果存在则更新流量，否则创建新的记录。

## 实体设计

与用户相关的实体设计，不需要导航属性，直接使用UserId作为查询时的索引即可。

### ProxyUsage

代理使用流量的记录，每个用户每天一条记录，添加适当的索引，方便查询。
流量以字节为单位，long类型。


### UserEntitlementDefinition

用户权益定义表，包含:

- DisplayName
- Description
- EntitlementCode: 权益代码，字符串，唯一索引
- EntitlementType: 权益类型，枚举值:ProxyUsage
- Unit: 权益单位，字符串
- UserEntitlements: 列表，导航属性，用来反查权益信息

### UserEntitlement

通用用户权益表，包含:
- UserId
- EntitlementDefinitionId：含导航属性，以查询权益信息
- ValueLimit: 权益值，long类型
- CurrentValue: 当前权益值，long类型; 默认值为0，不会在编辑接口暴露。
- ExpirationDate: 权益过期时间，DateTimeOffset类型，可空表示不过期
- StartDate: 权益开始时间，DateTimeOffset类型，

#### 接口说明

**权益验证接口**

先验证token是否有效，如果有效，则查询用户的权益信息，判断是否有对应的权益

- **接口地址**：GET /api/userCenter/GetEntitlement
- **请求头**：header: Authorization: {token}
- **请求参数**：EntitlementCode，必传
- **返回结果**: UserEntitlementDetail，未查到则直接返回403
- **额外说明**：要通过缓存用户的权益信息，避免频繁查询数据库，缓存时间为2分钟。
