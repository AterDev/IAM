# 重构说明

## 代码结构说明

- 实体类统一放在`src/Definition/Entity`文件夹下，按模块进行子文件夹划分。
- Dto在`src/Modules/`文件夹下，按模块和实体进行子文件夹划分。
- 前端在`src/ClientApp/WebApp`目录下。

当前修改都是针对`IAMMod`模块.

## 实体修改

1 对于所有实体类，去除`[Module]`特性.

## Client重构说明

1 对于类型，需要在当前实体内定义枚举类型，而不是使用字符串表示类型。如`Type,ConsentType/ApplicationType`等，均定义为枚举类型。

2 同时修改对应的`Dto`模型，将字符串类型改为枚举类型。

3 前端代码中，也需要使用枚举类型进行处理，选择合适的组件。

## 加密处理

对于 `UserManager/TokenManager` 中的密钥处理这一块，之前使用`_passwordHasher`，现在已经删除。需要直接使用`HashCrypto`类中的方法进行加盐处理。可参考`ClientManager`中的实现。

## Manager异常处理

在Manager中，统一使用`BusinessException`进行异常抛出处理，方便上层调用时进行捕获和处理。 使用 BusinessException时，只需要传入常量即可，而不是使用字符串硬编码。常量定义在`Localizer`中，不需要手动定义，它会利用源代码生成器，自动从资源文件中生成对应的常量类，目前支持 `Localizer.zh-CN.resx` 和 `Localizer.en-US.resx` 两个语言的资源文件。

## 构建项目

修改完成后，构建 `ApiService`项目，根据错误信息进行修正。
